## 밸런스 기준

| 기준 | 목표 |
| --- | --- |
| 일반 적 처치 시간 | 현재 층 기대 공격력 기준 기본 공격 2~5회 |
| 엘리트 처치 시간 | 기본 공격 8~12회 또는 시그니처 3~5회 |
| 보스 처치 시간 | 기본 공격 25~35회 또는 시그니처 8~12회 |
| 실수 허용도 | 일반전 3~5회 피격, 엘리트 3~4회 피격, 보스 강공격 2~3회 피격까지 생존 가능 |
| 동시 등장 | 일반적으로 1~3명, 보스 소환 포함 최대 4명 |
| 유물 제한 | 중복 획득 불가, 런당 최대 8개 권장 |

## 플레이어 기준값과 공식

| 항목 | 기본값 | 상한/규칙 |
| --- | --- | --- |
| 최대 HP | 100 | 유물·장비 포함 권장 상한 160 |
| 최대 AP | 6 | 유물 포함 권장 상한 9 |
| AP 재생 | 초당 1 | 전투 중 권장 상한 초당 2 |
| 기본 방어력 | 0 | 장비·유물 포함 권장 상한 45 |
| 기본 치명타 | 0% | 명시된 효과에서만 발생, 치명 피해 150% |
| 시작 콤보 | 0 | 오타/실패 시 0, 권장 UI 표시 상한 20 |
- 기본 피해 = 공격력 × 스킬 계수
- 방어 적용 후 피해 = 기본 피해 × 100 ÷ (100 + 방어력), 최종 반올림·최소 1
- 방어 스킬은 피해 감소율을 먼저 적용한 뒤 방어력 공식을 적용한다.
- 공격자 수치는 스킬 시작 시점에 고정하고, 대상의 방어력·보호막은 타격 시점 기준으로 계산한다.

## 플레이테스트 조정 규칙

- 1~3층에서 평균 2회 이하 피격으로 통과하면 일반 적 HP를 10% 올리거나 선딜을 0.1초 줄인다.
- 5층 보스 도달률이 60% 미만이면 교정 실패 피해를 36에서 30으로 낮추거나 보스 HP를 10% 낮춘다.
- 10층 도달률은 20~35%, 첫 클리어율은 8~15%를 목표로 한다.
- 특정 유물의 픽률이 70% 이상이고 해당 런 승률도 평균보다 15%p 이상 높으면 수치 하향 또는 발동 횟수 제한을 적용한다.
- 방어 스킬이 모든 공격의 정답이 되면 피해 감소율을 5%p 낮추기보다 지속시간을 0.1~0.2초 줄여 타이밍 난도를 유지한다.
