# 재화와 정산

<aside>
💰

재화와 정산은 런에서 획득한 가치가 메타 진행으로 어떻게 전환되는지를 정의합니다. 현재 확정된 핵심은 **사망해도 획득분의 환전 가치는 정산되고, 클리어 시 추가 보상이 붙는다**는 점입니다.

</aside>

## 재화

재화의 명칭과 종류는 **미정**입니다. 초기 구현에서는 하나의 기본 재화로 시작하고, 필요할 때 용도별 재화를 분리하는 방향을 권장합니다.

## 아이템 환전

- 런에서 획득한 아이템은 각각 **환전 가치**를 가집니다.
- 런 종료 시 보유 아이템의 환전 가치를 합산해 재화로 지급합니다.
- 구체적인 아이템별 환전 값은 밸런스 데이터로 관리합니다.

## 사망 정산

- 사망 시점까지 획득한 아이템의 환전 가치 총합을 재화로 지급합니다.
- 사망했다고 해서 해당 시점까지 획득한 아이템 가치가 전부 사라지지는 않습니다.
- 스테이지를 클리어하지 않았으므로 **스테이지 클리어 보상은 지급하지 않습니다**.

## 클리어 정산

- 획득 아이템의 환전 가치 총합을 재화로 지급합니다.
- 여기에 **스테이지 클리어 보상**을 추가 지급합니다.
- 따라서 동일한 아이템 획득량이라면 클리어가 사망보다 높은 총 정산을 제공합니다.

## 정산식

`사망 정산 = 획득 아이템 환전 가치 합계`

`클리어 정산 = 획득 아이템 환전 가치 합계 + 스테이지 클리어 보상`

## 사용처

재화의 구체적인 사용처는 아직 전부 확정되지 않았습니다. 후보는 다음과 같습니다.

- 장비 획득 또는 가챠
- 장비 관련 메타 진행
- 편의 기능 또는 장기 성장

<aside>
⚠️

실제 결제 BM, 유료 가챠, 월정액 등은 초기 제품의 핵심 검증 범위가 아니라 후속 범위입니다.

</aside>

## 설계 원칙

- 사망과 클리어의 차이는 **획득분 전부 몰수 여부**가 아니라 **추가 클리어 보상 유무**에서 명확하게 느껴져야 합니다.
- 결과 화면에서는 아이템 환전분과 클리어 추가 보상을 별도 항목으로 보여줍니다.
- 플레이어가 어떤 행동으로 얼마의 재화를 얻었는지 역산할 수 있어야 합니다.
