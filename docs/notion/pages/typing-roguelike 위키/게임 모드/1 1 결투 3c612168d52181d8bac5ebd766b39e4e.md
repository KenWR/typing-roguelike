# 1:1 결투

<aside>
⚔️

플레이어가 보유한 `영혼`을 사용해 싸우는 후속 PvP 모드 초안입니다.

</aside>

## 목적

- 탑에서 완성한 빌드의 가치를 PvP로 확장합니다.
- 타자 실력뿐 아니라 빌드 구성과 상대 패턴 판독을 경쟁 요소로 만듭니다.

## 참가 단위

- 계정 캐릭터 자체가 아니라 선택한 `영혼`을 전투 단위로 사용하는 방향을 기본 후보로 둡니다.

## 위험과 보상

- 패배 시 사용한 영혼이 삭제되는 고위험 규칙을 후보로 둡니다.
- 승리 보상, 랭크, 매칭 방식은 미정입니다.

## 설계 쟁점

- 실시간 동기 PvP인지 비동기 전투인지
- 입력 속도 차이에 대한 공정성
- 장비/유물 격차에 대한 매칭
- 영혼 소멸이 너무 큰 손실로 느껴지지 않는 보상 구조
- 네트워크 지연이 선딜·후딜 판정에 미치는 영향
