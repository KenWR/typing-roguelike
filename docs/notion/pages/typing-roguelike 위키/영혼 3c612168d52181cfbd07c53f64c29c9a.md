# 영혼

<aside>
👻

영혼은 탑에서 완성한 강력한 빌드를 PvP 결투에 가져가기 위한 별도 전투 자산입니다. PvE 성취를 보존하면서도 결투에 실제 리스크를 부여하는 개념입니다.

</aside>

## 정의

- **영혼**은 탑에서 보스를 클리어하고 나온 시점의 플레이어 빌드 상태를 기반으로 생성되는 PvP용 전투 자산이다.
- 장비, 스킬 구성, 유물 등 어떤 요소를 정확히 복제할지는 **미정**이다.
- 원본 계정의 영구 장비를 직접 잃게 하기보다, 결투용 복제체 또는 스냅샷에 가까운 개념으로 본다.

## 생성

- 기본 방향은 **탑의 보스를 클리어하고 생환했을 때 생성**하는 것이다.
- 한 번의 성공적인 런이 하나의 영혼을 만들 수 있는 구조를 우선 검토한다.
- 생성 시 빌드 정보와 주요 성과를 기록해 어떤 런에서 나온 영혼인지 식별 가능하게 한다.

## 결투

- 영혼은 1:1 PvP 결투에 사용한다.
- 플레이어는 보유한 영혼 중 하나를 선택해 결투에 참가하는 구조를 기본으로 한다.
- PvP 밸런스는 영혼의 빌드 강도뿐 아니라 타자 숙련과 대응 능력도 승패에 영향을 주도록 설계한다.

## 소멸

- 핵심 아이디어는 **결투에서 패배한 영혼이 삭제될 수 있다**는 것이다.
- 정확히 패배 즉시 삭제할지, 특정 패배 조건이나 소모 횟수를 둘지는 **미정**이다.
- 소멸 규칙은 영혼에 희소성과 서사를 부여하지만, 지나친 손실 회피 행동을 만들 수 있으므로 테스트가 필요하다.

## 설계 의도

- 탑에서 완성한 인상적인 빌드에 런 종료 이후의 가치를 부여한다.
- PvP 승패에 실제 긴장감을 만든다.
- 영구 계정 성장과 PvP 전력 사이에 완충층을 둔다.
- 강력한 ‘졸업 빌드’ 자체가 수집·자랑·대전 콘텐츠가 되게 한다.

## 미정 사항

- 영혼에 포함되는 데이터 범위
- 한 계정의 영혼 보유 한도
- 패배 시 즉시 삭제 여부
- 승리 보상
- 동일 영혼의 반복 출전 제한
- 영혼 간 전력 차이를 보정하는 매칭 방식
