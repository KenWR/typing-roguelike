# 에셋 크기

웹게임은 **1920×1080 기준 데스크톱 레이아웃**으로 잡고, 에셋은 선명도를 위해 원본을 2배로 제작한 뒤 CSS에서 절반 크기로 표시하는 방식을 추천합니다. 타자 전투는 읽기 쉬움이 가장 중요해서, 몬스터보다 HUD와 커맨드 영역을 우선 확보해야 합니다.

| 요소 | 화면 표시 크기 | 제작 원본 권장 | 비고 |
| --- | --- | --- | --- |
| 플레이어블 캐릭터 | 220×300 px | 440×600 px | 하체가 잘린 반신~전신. 좌하단 배치 |
| 일반 몬스터 | 160×200 px | 320×400 px | 다수전에서 3명까지 무리 없이 배치 |
| 엘리트 몬스터 | 220×280 px | 440×560 px | 일반 적보다 약 1.3배 |
| 보스 | 400×480 px | 800×960 px | 실루엣과 준비 모션이 명확해야 함 |
| 소환체·소형 적 | 100×130 px | 200×260 px | 보스전 최대 2~3개 기준 |
| 무기 아이콘 | 96×96 px | 192×192 px | 장비 카드·인벤토리 공용 |
| 반지·유물 아이콘 | 80×80 px | 160×160 px | 유물 선택지에서 3개를 나란히 표시 |
| 스킬 아이콘 | 56×56 px | 112×112 px | 전투 HUD용 |
| 장비 카드 일러스트 | 320×180 px | 640×360 px | 가챠·획득·상세 화면 공용 |
| 적 초상화 | 96×96 px | 192×192 px | 다수전의 게이지/상태 패널용 |

권장 전투 화면 배치는 다음 정도가 안정적입니다.

```
┌──────────────────────────────── 1920 × 1080 ────────────────────────────────┐
│ 적 초상화·HP·공격 게이지 영역 (상단 170px)                                    │
│                                                                              │
│                    몬스터 전투 무대 (중앙 약 650px)                          │
│     플레이어 220×300                         일반 적 160×200 × 최대 3       │
│                                             보스 400×480                     │
│                                                                              │
│ 스킬·HP·AP·상태 (좌하단)        커맨드 입력창·완성 문자열 (하단 약 170px)     │
└──────────────────────────────────────────────────────────────────────────────┘
```

특히 중요한 기준은 세 가지입니다.

- 보스의 준비 모션은 이펙트를 포함하지 않은 **몸체 실루엣만으로도 400×480px 영역에서 구분**되어야 합니다.
- 일반 적은 3명이 동시에 등장해도 각자 **이름·공격 게이지·위협 아이콘**이 겹치지 않게 160×200px 내외로 제한합니다.
- 유물과 무기는 아이콘만으로도 기능 계열을 구분해야 하므로, 80~96px 표시 크기에서 읽히는 강한 실루엣을 우선합니다.

반응형은 전투 중 UI를 축소하기보다, **최소 1280×720을 지원 하한**으로 두는 편이 좋습니다. 그 이하 폭에서는 전투 무대를 크게 줄이기보다 브라우저 확대 안내 또는 간소화 레이아웃을 고려하는 것이 타자 판독성에 유리합니다.
