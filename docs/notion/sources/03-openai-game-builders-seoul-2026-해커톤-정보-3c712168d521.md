## 행사 개요
- 행사명: **OpenAI Game Builders Seoul**
- 주최: **OpenAI**
- 운영: **컴투스홀딩스**
- 지원/기술 연계: 컴투스 계열의 **Hive** 게임 백엔드 플랫폼
- 핵심 주제: **Codex를 활용해 실제 플레이 가능한 게임을 만들고, 개발 과정에서 AI와 어떻게 협업했는지 보여주는 것**
- 전체 흐름: 온라인 예선 Track 1 → 40팀 선발 → 8월 31일 서울 오프라인 본선 → Track 1 발표/시연 + Track 2 현장 5시간 빌드
## 우리가 만들어야 하는 것
Track 1에서 요구되는 핵심 결과물은 단순한 기획서가 아니라 **직접 플레이할 수 있는 게임 프로토타입**입니다.
필수 조건:
- 게임의 코어 플레이에서 재미를 확인할 수 있어야 함
- **브라우저에서 바로 실행되는 웹 빌드**여야 함
- 심사위원이 별도 승인이나 복잡한 설치 없이 접속 가능해야 함
- 개발 과정에 **Codex를 사용해야 함**
- 기존 프로젝트를 활용해도 되지만, 해커톤 기간 동안 새로 개발·개선한 내용을 명확히 표시해야 함
현재 typing-roguelike 프로젝트를 제출한다면, 기존 작업분과 2026-08-04\~08-26 챌린지 기간에 새로 만든 부분을 구분해서 기록하는 것이 중요합니다.

## 팀/본선 참가 규칙
- 팀 구성은 **최대 3명**
- 온라인 심사를 통해 **40팀** 선발
- 팀 참가의 경우 본선에는 **대표 1인**이 참석
- 대표자가 참석하기 어려운 정당한 사유가 있으면 운영진 사전 승인 후 다른 팀원이 참석 가능
- 본선에서 Track 1 게임을 직접 발표·시연해야 최종 수상 후보가 될 수 있음
- Track 2는 Track 1 본선 진출팀의 현장 대표자 1명만 참가 가능
## 예선 심사 기준 — 5개 항목
1. **Playability** — 게임이 실제로 잘 작동하는가?
2. **Originality** — 아이디어와 플레이 방식이 독창적인가?
3. **Codex Collaboration** — Codex를 효과적으로 활용했는가?
4. **Release Potential** — Hive를 통해 실제 서비스로 확장할 수 있는가?
5. **Presentation** — 발표와 시연으로 게임 및 개발 과정이 명확히 전달되는가?
### typing-roguelike 관점 체크
- 타자 + 실시간 전투라는 코어 루프를 처음 1\~2분 안에 이해할 수 있어야 함
- 복잡한 콘텐츠 양보다 **실제로 동작하고 재미가 드러나는 짧은 완성 루프**가 우선
- Codex가 구현한 기능/문제 해결 사례를 개발 로그로 남길 것
- 브라우저 배포와 외부 접속 테스트를 제출 전에 완료할 것
## Track 1 제출물
### 필수
- 대표 신청자 정보
	- 성명
	- 팀명
	- 소속(선택 입력란 존재)
	- 본선 오프라인 행사 참석 가능 여부
	- 긴급 연락처
	- 거주 국가 / 생년월일 / 필수 약관 및 개인정보 동의
- **게임 제목**
- **게임 소개 200자 이내**
- **플레이 가능한 게임 링크**
	- 브라우저 즉시 실행
	- 심사 기간 동안 접속 가능
	- 별도 승인 없이 접근 가능
	- 로그인 필요 시 테스트 계정 제공
	- 조작법과 실행 방법 안내
- **게임 썸네일**
	- JPG 또는 PNG 권장
	- 16:9 권장
	- 최대 10MB 권장
### 선택 제출 — 가산점 가능
- **3분 이내 데모 영상 링크**
	- 게임 소개
	- 실제 플레이
	- 핵심 기능
- **Codex 활용 과정 설명**
	- Codex를 어디에 사용했는가
	- 어떤 기능을 구현했는가
	- 어떤 문제를 해결했는가
	- 사람이 직접 결정한 부분은 무엇인가
<callout icon="📌" color="blue_bg">
	공식 제출 화면상 별도의 PDF 기획서/사업계획서는 필수 제출물이 아닙니다. 핵심은 **실행 가능한 웹 게임 + 게임 소개 + 썸네일**이며, 데모 영상과 Codex 활용 설명은 선택 항목입니다.
</callout>
