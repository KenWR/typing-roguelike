# ✨ 스킬과 커맨드

> [Notion에서 열기](https://app.notion.com/p/3c612168d5218125a530d0f6d87b1a21?pvs=204)
> 이 문서는 2026-08-26에 로컬로 추출한 원문 스냅샷입니다.

<callout icon="✨" color="blue_bg">
	스킬과 커맨드 페이지는 플레이어 입력이 실제 전투 효과로 이어지는 규칙을 정의합니다.
</callout>
## 스킬 구조
스킬은 장비를 통해 제공되며, 기본 기술과 시그니처 기술로 구분할 수 있다. 장비 등급에 따라 기본 기술 1개와 시그니처 기술 1\~2개를 제공할 수 있다.
## 커맨드
커맨드는 스킬을 실행하기 위해 플레이어가 정확히 입력해야 하는 문자열이다.
- 커맨드 언어는 한국어, 영어 또는 사용자 선택 방식 중 **미정**이다.
- 커맨드는 전투 중 즉시 판독할 수 있어야 한다.
- 입력 난이도는 스킬 성능, 행동력 소비, 타이밍과 함께 설계한다.
## 입력 성공
입력이 성공하면 플레이어가 **내가 친 스킬이 실제로 동작했다**고 즉시 인지할 수 있어야 한다.
권장 피드백 요소:
- 커맨드 성공 표시
- 콤보 증가 이펙트
- 해당 스킬의 시각 효과 또는 캐릭터 모션 시작
- 짧은 효과음
- 현재 스킬 상태 표시
## 선딜
선딜은 스킬이 시작된 뒤 완성되기까지의 시간이다. 선딜이 있는 스킬은 이 구간이 플레이어와 적 모두에게 판독 가능해야 한다.
## 시전 완료
선딜이 종료되면 스킬이 완성된 것으로 간주한다. 적의 경우 이 시점부터 다음 공격 게이지가 다시 충전될 수 있다.
## 후딜
후딜은 스킬이 완성된 뒤 상대에게 도착하기까지의 시간이다. 입력 성공 뒤 후딜이 존재하는 스킬은 플레이어가 현재 결과를 기다리는 상태임을 이해할 수 있도록 표시한다.
만약 근접공격의 경우, 후딜시에 입력 도착 시 기존 공격을 성공처리하고 입력 받은 후딜 시작
## 타격 시점
후딜이 끝나는 순간 스킬의 피해·방어·상태 효과 등이 실제로 적용된다.
## 생명주기
`사용자 입력 → 스킬 시작 → 선딜 → 시전 완료 → 후딜 → 타격 시점`
## 방어 스킬
`매직실드`, `방패들기`처럼 적 공격 도착 전에 입력하여 대응하는 스킬을 지원한다. 방어 성공 조건은 적의 타격 시점과 방어 스킬의 유효 구간을 기준으로 판정하는 방향이 적합하다.
## 설계 원칙
- 입력 성공과 효과 적용 사이의 시간을 숨기지 않는다.
- 강한 스킬은 긴 커맨드, 높은 행동력 비용, 긴 선딜/후딜 등 여러 비용 축으로 조정할 수 있다.
- 커맨드 자체의 난이도가 재미를 해치지 않도록 시각적 판독성과 피드백을 우선한다.
## 콤보
- 오타 없이 단어를 입력할 경우 콤보 게이지 상승
- 추가 데미지 %부여
- 콤보가 끊어질 경우 소리로 알림
